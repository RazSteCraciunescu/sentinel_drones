# Changelog

All notable changes to this project are documented here.

## 0.1.0 - 2026-09-12

### Added

- Simulation-only FastAPI service with synthetic fleet state.
- Mission safety gates for altitude, geofence, restricted zone, maintenance, launch battery, link quality, and recovery reserve.
- Telemetry freshness, sequence, range, and deterministic fail-safe checks.
- Closed safe-command gateway for hold, return-home, and land actions.
- Observer, operator, auditor, and maintainer role separation.
- Process-local SHA-256 audit chain and assurance metrics.
- Unit, API, contract, security, resilience, property, and browser test layers.
- Requirements, test cases, traceability, risk register, FMEA, threat catalog, and control mapping.
- Postman, k6, Locust, Docker, PowerShell, and repository utility assets.
- GitHub Actions quality/security workflows and Dependabot configuration.
- Architecture, threat model, safety case, standards context, learning labs, exploratory charters, and sample reports.
